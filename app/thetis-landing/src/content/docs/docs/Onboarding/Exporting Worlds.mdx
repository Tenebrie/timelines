It's possible to export your worlds as a JSON file. You can then use this file to import your data into another Neverkin environment, transfer them to another account, or to act as a backup.

You can find the import/export page in your user preferences:

<Image src={dataExport01} alt="Data import/export page" />

Pressing "Export" will create a single file containing all your world data that you can then download. The file is kept available for 1 hour before being deleted.
