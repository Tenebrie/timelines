Currently Neverkin doesn't natively support importing or exporting data to different applications. While I am well aware this is not a solution, one way to migrate would be to use the MCP server to programmatically recreate your data in the new format.

See the [MCP API documentation](./using-ai-agents) for guidance.

If you would like to migrate data between Neverkin environments, or just export them in a json format, you may want to check the [Importing and exporting worlds](./importing-and-exporting-worlds) page.
