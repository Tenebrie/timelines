Currently Neverkin doesn't natively support importing data from, or exporting it to, other applications. While I am well aware this is not a solution, one way to migrate would be to use the MCP server to programmatically recreate your data in the new format.

See the [MCP API documentation](./using-ai-agents) for guidance.

If you would like to migrate data between Neverkin environments, or just export your worlds in JSON format, you may want to check the [Exporting worlds](./exporting-worlds) and [Importing worlds](./importing-worlds) pages.
