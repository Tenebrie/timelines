Core Neverkin features are exposed via an MCP server at https://app.neverkin.com/mcp. Choose your favorite agent and try using it!

The MCP server supports full OAuth authentication.

<Aside type="tip" title="Fun fact">
The Neverkin MCP server is internally named Orpheus!
</Aside>

## Using agents responsibly

I recommend sandboxing your agent in its own account, and giving it either worlds of its own or shared worlds you've granted it read and/or write permission on.

Editing the same world that an agent is working in is safe, but the MCP server does not operate on a live collaboration layer. An agent may read a slightly out-of-date document (typically up to a few seconds), and it may overwrite your changes.
