Neverkin Desktop for Windows can be downloaded from the [Downloads](https://neverkin.com/download) page.

Direct download link: [neverkin-desktop-win32-x64.zip](https://github.com/Tenebrie/timelines/releases/latest/download/neverkin-desktop-win32-x64.zip)

Neverkin Desktop doesn't currently have known issues when running on Windows and should be running out of the box. If that's not true in your experience, your solution may appear on this page if you let us know!
