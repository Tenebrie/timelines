You can download the latest Neverkin Desktop version from the [Downloads page](https://neverkin.com/download) of the website. New releases are published simultaneously with the main application.

The desktop version is designed to work completely offline and does not connect to the cloud in any way. Neither will it check for updates. I recommend downloading a new version from time to time, but it's optional if the version you have keeps working.

Neverkin Desktop has full feature parity with the web version, with a few notable exceptions. These include:

- Collaboration features are effectively disabled as each instance of the application is separate.
- Login with Google is not available.

:::note
Neverkin Desktop is a fresh development that may contain bugs. Please report any issues you encounter!
:::
