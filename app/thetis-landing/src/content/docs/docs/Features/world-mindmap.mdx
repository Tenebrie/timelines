The **Mindmap** is a place for your visualizations. The sky is the limit to what you want to visualize. It could be a chart of character relationships; a family tree; physical layout of rooms in a dungeon or whatever you want to use it for.

<Image src={appShowcase01} alt="The Mindmap view, showing a chart of character relationships." />

## Working with the Mindmap

While working with the mindmap, you are working with **Nodes**. A node is a container for another entity type, like an actor, and you create a node by dragging something from the outliner into the mindmap workspace.

<Image src={mindmap01} alt="A few basic mindmap nodes example" />

Alternatively, you can right click (or press Space) in the workspace to open a quick select menu. Search for your entity, or create one directly from this view.

<Image src={mindmap02} alt="Mindmap quick select dropdown" />

You may edit the entities by double clicking their node.

<Aside type="tip">
An entity may have multiple nodes. It can be useful if you'd like to use the same character in multiple story arc charts or family trees. A node always has exactly one parent entity, or none at all. 
</Aside>

### Node linking

Nodes can be linked together to show their relationship. To link a node, drag a line from the slot in the top right corner of the node, or simply start dragging a node with Shift key held down. Dropping the wire onto another node will link to it, or dropping it in the empty space will open the quick select menu, allowing you to quickly create a node and link it immediately.

<Image src={mindmap03} alt="Two nodes linked together" />

You can also double-click the wire to add a label to it, or flip the link direction.

<Aside type="note">
While node links and mentions may look similar, they are not the same concept. You can mention entities and link nodes independently from each other.
</Aside>

### Deleting nodes

Right click the node and select "Delete" to remove the node. This does not delete the underlying entity, only this specific node in the mindmap. You may also press the **Delete** key (**Backspace** on a Mac) to delete the node.

### Plain nodes

You can also create plain nodes that don't link to any other entity. Use them for prototyping, quick creation of ideas or to explain in detail why this character hates that particular establishment.

Plain nodes can have full rich text description, but they don't show up outside the mindmap.
