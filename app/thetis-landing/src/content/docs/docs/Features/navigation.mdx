Basic navigation in Neverkin is handled through two primary components: the **navigator** and the **sidebar**.

## Navigator

The **navigator** is a floating panel at the top of your screen that provides you access to different features in the global scope.

<Image src={baseNavigator01} alt="The top bar, showing the main features and options available in Neverkin." />

Listing the controls from left to right:

- **Worlds hamburger dropdown** - a quick way to switch between worlds.
- **World button** - returns you to the last opened world.
- **Home button** - returns you to the home page. Clicking the arrow gives you more options.
- **Tools** - a selection of totally random tools that may or may not be useful.
- **Admin** (only for admin users) - administration tools.

## World sidebar

The **sidebar** is a contextual panel that appears when you select an entity. It provides detailed information about the selected entity and allows you to edit its properties.
